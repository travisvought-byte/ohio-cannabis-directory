# Ohio event maintenance

Visitors and organizers can submit an event by email from the directory or through the GitHub event issue form. These are research leads; a submission does not publish automatically.

Before publication, check the organizer’s official page for date, venue, audience, registration link and cancellations. Record the review date on `event_routes` and scoped evidence on the canonical `events` record. Preserve the Women’s Cannabis & Wellness Expo’s featured priority unless the directory owner changes it.

Recheck current events every two weeks and during the week before an event. The browser hides expired dates automatically. The Upcoming events box lists every confirmed future date in `event_routes`, featured events first, then by date; there is no look-ahead cut-off. Only add an event route the directory intends to promote. Regenerate after adding or changing an event, and check both the main directory and shared community view.

This is a maintenance process and submission route, not an unattended scheduled updater. New dates, cancellations and venues need primary-source review.
