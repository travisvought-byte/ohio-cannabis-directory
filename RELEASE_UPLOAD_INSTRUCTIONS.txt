Ohio Cannabis Ecosystem Directory — how to publish a release

The live site is built from this GitHub repository. Edit the canonical data
and release.json, run the builders and checks documented in README.md, and
publish the reviewed commit. Do not upload a ZIP as the site contents.

The current version and date are in release.json. Current record counts are
in README.md. This file intentionally repeats neither, so it cannot go stale.

Archiving a release (separate from publishing GitHub Pages):
1. Confirm release.json, CITATION.cff and .zenodo.json carry the same version.
2. Confirm the repository is switched on in Zenodo's GitHub settings.
3. On GitHub, create a release with tag v<version> (for example v4.36)
   on the commit that carries that version.
4. Zenodo archives the release and issues a DOI. Add the DOI to README.md
   and CITATION.cff only after Zenodo shows it.

Private CRM and business-card files are not published.
